⚖️ Mode standard — règles fixées a priori
Entités
  • E1 : pas mot pour mot dans sa page → retirée
  • E2 : entité niée → gardée, marquée niée
  • E3 : confiance du modèle moyenne ou faible → retirée
Relations
  • R2 : relation qui affirme une entité niée → retirée
  • R3 : relation créée par SGCE non ancrée → retirée
  • une entité retirée emporte ses relations
Confiance : élevée, moyenne ou faible selon le nombre de signaux faibles
➜
🎚️ Mode précision — vote appris
  • chaque élément décrit par des variables binaires issues des agents (type, section, preuve, mots…)
  • régression logistique : un poids par variable, score de fiabilité entre 0 et 1
  • on garde la part k % des éléments les mieux notés
k = 100 % : rappel maximalk = 30 % : précision maximale
🔒 Validation croisée : appris sur une moitié des dossiers, appliqué à l'autre, puis l'inverse
